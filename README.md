## 1论AI发展的正确路线，预设AIvs生成AI
- 我用ppt来说明一下，AI发展的正确路线是什么，首先来看AI人工智能，它分为了生成AI和预设AI两条路线，目前生成AI大厂基本都是入不敷出状态，缺乏商业变现，它所代表的前AI时代即将崩盘，股东已经用脚投票了，另一条路线是预设AI，代表的是后AI时代，这是一条可以无限拓展的拓扑路线，商业变现潜力极大，我来给你说明一下，生成AI和预设AI的区别，从工作方法上，前者生成新内容，后者根据预设输出内容，从输出结果看，前者根据概率输出，后者固定输出，从判断好坏看，前者靠准确率命中率，后者靠预设一致性，从电力消耗看，前者需要大量电力，后者只需要维持充电，从token看，前者就是在烧钱，后者不需要token，从成本看，前者用户越多成本越高，后者成本和用户无关，从可控性看，前者无法精确控制方向，后者锁定方向可控，从智能水平看，前者依赖训练样本，后者依赖工程师水平，从角色扮演看，前者无法保证人格稳定，后者可以保持，从情感产品看，前者上下文记忆有限，后者固定储存记忆，目前资本押注的是不稳定不可控的生成AI，路线错误导致他们现金流疯狂折损，无法进行高效的商业变现，就是个玩具而已，军方的话会更喜好稳定可控不消耗token的预设AI，下面讲一下两者AI的适用范围，生成AI适合检索、验证、处理机械重复工作，比如代码、美术底稿、配乐、配音、理性文本，但它并不适合处理感性文本，因为它不知道什么叫感性，是绝对理性产物，而预设AI适用于除了生成AI范围内的一切领域，如不误伤平民无人机、纳米精准医疗、文学创作，在机器人领域，预设AI可以满足心理需求，如日常陪伴、情感需求、心理治疗等。

## 2生物基因技术vs机械飞升造人技术
- 这个视频讲一下生物飞升和机械飞升的区别啊，从大脑来看，生物基因飞升是生物大脑，是理性和感性的双生活核而机械大脑是芯片大脑，是绝对理性的单死核，接下来细说下二者的区别，从感性理性看，生物是理性和感性的结合体，没有绝对理性和绝对感性，最多只能是99比1，而机械是绝对理性，无感性的机器，理性程度看预设链条，上限是人类认知的边界，从生命看，基因飞升是造了一个碳基新生命，他是独立个体，受伦理限制，有自己的思想，而机械飞升造的是硅基拟态物，并不具有生命，永远都是死的，不受伦理限制，从特点看，生物技术是不稳定且不可控的，而机械技术是稳定的可控的，用例子来说，在生物技术上，人类就算刺激生物电，让基因重新生成断肢，但无法100%知道基因编程蓝图，最终生长出来的新肢体是不可控的会畸变的，而机械技术上，人类可以用机械体还原人的身体构造，用死核模拟活核，只要预设链条足够多，完美模拟人类行为，那么你永远不知道是真人还是伪人，了解了两种化学飞升路线，我们来讨论下具体问题，换头技术为什么不乐观？，一是大脑本身会自然老化，二是脱离原本身体，大脑会快速衰亡，三是需要消耗神经细胞连接新身体，四是大脑和新身体会排异，互相攻击对方，为什么无法真正实现上传意识到机械体？，一是碳基生物大脑和硅基机械体本身不兼容，二是意识的载体是大脑，现有科技无法提取意识，三是机械是死物，不可能有意识，只有预设链条，那么要如何复制意识到机械体呢？，这个问题很简单，可以用预设链条进行模拟，但机械体缺乏拓展认知边界的理性推演能力，看似复制意识，实际上不是真的“人”。
